# 수학 기초 진단평가 홈페이지 — GitHub Pages 버전

**설치할 프로그램이 없습니다.** GitHub Pages에 올린 다음 선생님이 학생 링크를 복사해서 전달하면 됩니다.

## 홈페이지를 올리는 방법 (처음 한 번)

1. [GitHub](https://github.com/)에 로그인하고, 오른쪽 위 `+` → **New repository**를 누릅니다.
2. Repository name에 `math-quiz`를 입력하고 **Public**을 선택하여 **Create repository**를 누릅니다.
3. 저장소의 **Add file → Upload files**에서 이 압축파일 안에 있는 파일 **5개**(`index.html`, `student.html`, `style.css`, `questions.js`, `app.js`)를 모두 선택해 올립니다. **ZIP 파일 자체를 올리는 게 아닙니다.**
4. 아래의 **Commit changes**를 눌러 저장합니다.
5. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택하고 **Save**를 누릅니다.
6. Pages 설정 화면에 표시되는 사이트 주소로 접속합니다. 보통 `https://본인아이디.github.io/math-quiz/` 형태입니다. 배포에 몇 분 정도 걸릴 수 있습니다.

## 과외에서 사용하기

1. 선생님 PC에서 사이트 주소를 열면 **선생님 화면**이 나타납니다.
2. 화면 상단의 **학생 접속 링크 복사**를 누릅니다.
3. 복사한 링크를 카카오톡·문자 등으로 학생에게 전달합니다.
4. 학생이 아이패드에서 링크를 열면 **학생 화면**이 나타납니다.
5. 학생은 문제별로 답을 선택하거나, 애플펜슬로 정답과 풀이 노트에 필기한 뒤 각 문항 오른쪽 위의 **제출**을 누릅니다.
6. 해당 문항에 제출된 답과 필기가 선생님 화면에 자동으로 표시됩니다.

> 선생님과 학생의 브라우저가 **둘 다 열려 있어야** 답안을 전달할 수 있습니다. 새로고침하면 접속 링크가 바뀔 수 있으므로, 새로고침한 뒤에는 새 학생 링크를 전달해 주세요.

## 주요 기능

- 20문항 모두 **한 페이지에 세로로 표시**됩니다.
- 객관식: 보기 한 개 선택 → 문제별 **제출**.
- 손글씨 단답형: **정답** 입력 칸 + **풀이 노트**.
- 모든 문항: 애플펜슬/손가락/마우스 필기, **되돌리기**, **지우기**.
- 선생님: 학생이 제출한 선택지·정답 필기·풀이 노트를 동일한 문항 아래에서 확인.
- 실시간 필기 전송이나 손글씨 자동인식 **없음**. 학생이 제출할 때만 전송.
- 학생의 작성 내용과 선생님이 받은 답안은 **각자의 브라우저에 임시 저장**됩니다. 선생님 브라우저의 사이트 데이터를 지우면 받은 답안도 사라집니다.
- 외부 데이터베이스·Firebase·Node.js·유료 AI API **불필요**.

## 문제 바꾸는 방법

`questions.js` 파일에서 문제 제목(`prompt`)과 선택지(`options`)를 변경할 수 있습니다. `type`이 `choice`이면 객관식, `ink`이면 손글씨 단답형입니다. 현재 20문항은 이전 진단평가의 1~20번을 바탕으로 작성되어 있습니다.

## 알아둘 제한 사항

- 이 버전은 **동시에 과외하는 학생 1명 + 선생님 1명**을 위해 제작되었습니다.
- 전송은 브라우저 간 직접 연결(WebRTC)이며 무료 **PeerJS Cloud 신호 서버**를 사용합니다. 학교·회사 네트워크 등 일부 환경에서는 연결이 제한될 수 있습니다. 안정적인 상용 서비스 수준을 보장하지 않습니다.
- **선생님 화면이 닫힌 상태에는 새 답안을 서버에 보관하지 않습니다.** 학생이 연결되면 미전송 답안의 전송을 재시도합니다.
- 브라우저 저장 내용은 사용자가 데이터를 삭제하거나 시크릿 모드를 종료하면 사라질 수 있습니다. 이 버전에는 교사 로그인·서버 백업·개인정보 보호를 위한 별도 인증 절차가 없습니다. **학생 이름·연락처 같은 개인정보를 문제나 답안에 적지 마세요.**
- 이 버전은 GitHub에 등록된 사용자 계정을 인식하지 않습니다. GitHub는 홈페이지 파일을 게시하는 용도로만 사용합니다.
- 처음에는 **PC와 아이패드 두 기기**로 간단한 객관식 1문항과 손글씨 1문항을 테스트한 뒤 본격적으로 사용하세요.
