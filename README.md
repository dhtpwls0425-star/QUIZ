# 전기과 신입생 수학 진단평가 (20문항)

GitHub Pages에서 실행하는 개인 과외용 퀴즈입니다. 학생은 문제마다 답안을 제출하고, 선생님은 제출된 선택지·정답 필기·풀이 노트를 확인합니다.

## 사이트 주소

- 선생님: https://dhtpwls0425-star.github.io/QUIZ/
- 학생: 선생님 화면 상단의 **학생 접속 링크 복사** 버튼으로 전달합니다.

## 달라진 점

- 기존의 지나치게 쉬운 계산 문제를 제외하고 **분수·비례·문자식·방정식·함수·복소수·지수·로그·삼각함수·극한·미분·적분** 등으로 20문항을 다시 구성했습니다.
- 선생님 화면 상단의 **전체 초기화** 버튼을 누르면 확인 창이 나타납니다. 확인 시 모든 객관식 선택, 정답 필기, 풀이 노트, 제출 기록을 삭제합니다.
- 학생이 연결돼 있으면 양쪽 화면에 초기화가 적용됩니다. 잠시 끊어져 있다면 학생이 같은 선생님 화면에 다시 연결될 때 초기화됩니다.
- 문항별 제출 방식, 20문항 세로 배치, 학생의 자유 필기 기능은 유지했습니다.

## 사용법

1. 선생님이 사이트 기본 주소를 열어 둡니다.
2. 화면 위의 **학생 접속 링크 복사**로 학생에게 링크를 전달합니다.
3. 학생이 아이패드에서 링크를 열고 해당 문제를 풉니다.
4. 학생은 문제 우측 상단 **제출** 버튼을 눌러 답안과 풀이 노트를 전송합니다.
5. 선생님이 해당 문제에서 학생의 제출 내용과 참고 정답을 확인합니다.

## 문제 바꾸기

`questions.js`에서 `prompt`(문제), `options`(객관식 보기), `answer`(선생님에게 표시할 참고 정답)를 수정할 수 있습니다.

## 유의 사항

- 동시에 선생님 1명과 학생 1명이 접속하는 소규모 과외용입니다.
- 실제 실시간 필기 공유가 아니라 **제출 버튼을 눌렀을 때만** 답안이 전송됩니다.
- 답안은 브라우저 임시 저장소에 기록되며, 별도 백업 서버는 없습니다. **전체 초기화 후 복원할 수 없습니다.**
- 연결에 PeerJS 기반 WebRTC를 사용하므로 일부 네트워크에서는 전송이 제한될 수 있습니다.
- GitHub Pages에 공개된 정적 사이트이므로 학생 이름이나 연락처 같은 개인정보를 넣지 마세요.
- 실제 사용 전에 PC와 아이패드에서 제출 1회 및 초기화 1회를 시험해 보세요.
